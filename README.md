# 🎭 공연 허브 — 「그건 문제가 아니야」

인터랙티브 덜미쇼 「그건 문제가 아니야」(박첨지 고민상담소)의 **공연 운영 링크 허브**.
A moment lab / 현대연희

👉 **https://bsg980601-creator.github.io/show-hub/**

## 왜 깃허브에 올려두는가

공연 서버는 공연장마다 IP가 바뀐다. 그래서 링크를 적어두면 다음 공연에서 죽는다.
이 페이지는 **주소가 고정**이고, 안에서 공연 맥북 IP만 새로 넣으면 전 링크가 따라간다.
넣은 IP는 그 기기 브라우저에 저장되므로 다음에 열면 그대로다.

| 여는 곳 | 주소 | 특징 |
|---|---|---|
| 공연장(자가망) | `http://<맥북IP>:8899/hub` | 서버 생존 표시등까지 동작. **인터넷 불필요** |
| 어디서나 | 위 깃허브 페이지 | 인터넷 필요. IP만 넣으면 링크 동작 |

두 곳이 **같은 파일**이다(`index.html`). 로컬 서버가 이 파일을 그대로 내보내므로 내용이 갈라지지 않는다.

## 쓰는 법

1. 공연 맥북에서 `700_공연네트워크/공연망_시작.command` 실행 → 출력된 IP 확인
2. 허브를 열고 그 IP를 입력 → 적용
3. 장면 순서대로 링크를 탄다

망이 바뀌면 맥북에서 `망변경_적용.command`(QR 재생성), 허브에서는 IP만 다시 넣으면 된다.

## 보안

- **암호·PIN은 이 저장소에 없다.** 허브에서 "암호 입력·수정"으로 오퍼 기기에 한 번 넣으면
  그 브라우저(localStorage)에만 남고, 어디에도 전송되지 않는다.
- 링크가 가리키는 서버는 전부 **사설망(LAN) 전용**이라 인터넷에서 접근되지 않는다.

### 기기 배치
- **맥북** — OBS 스위칭 · 카메라 2대 캡쳐보드 직결 · 서버 5종
- **맥미니** — 카메라 3번 직결 · 브라우저 화면(뷰티·얼굴필터·합성) 자체 구동

⚠️ 브라우저 카메라는 `localhost`·HTTPS에서만 열린다. 맥미니가 맥북 IP로 접속하면 카메라가 차단되므로,
맥미니는 `맥미니_송출시작.command`로 **자체 릴레이**를 띄우고 `localhost`로 열어야 한다.
